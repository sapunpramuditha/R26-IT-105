# Smart Recruiter – AI-Powered Recruitment Analysis System

An intelligent AI-driven recruitment platform designed to improve the fairness, accuracy, and efficiency of technical candidate evaluation. The system combines resume analysis, GitHub profile evaluation, adaptive AI interviewing, visual behavior monitoring, and speech-based behavioral analysis to provide a comprehensive candidate assessment experience.

---

##  Project Overview

Traditional recruitment systems mainly rely on keyword matching and manual interviews, which often fail to accurately evaluate a candidate’s true technical abilities, emotional state, and communication skills.

The **Smart Recruiter** system introduces multiple AI-powered components that work together to create a fair, intelligent, and data-driven recruitment process.

This research project focuses on:

* Resume and GitHub profile analysis
* AI-driven adaptive interviewing
* Real-time visual behavior monitoring
* Accent-independent speech behavior analysis
* Explainable competency scoring

---

##  Main Objectives

* Improve candidate evaluation accuracy using AI techniques
* Reduce recruitment bias and unfair filtering
* Detect implicit technical skills using Knowledge Graphs
* Create adaptive AI interviews based on candidate stress levels
* Analyze candidate confidence, hesitation, and vocal stress
* Build a scalable and intelligent recruitment ecosystem

#  System Workflow

1. Candidate uploads resume and GitHub profile
2. Resume parser extracts technical skills
3. GitHub repositories are analyzed
4. Skill Knowledge Graph generates competency scores
5. AI interviewer conducts adaptive interview
6. Visual behavior analysis monitors eye gaze and stress
7. Audio analysis detects confidence and hesitation
8. Final AI-generated evaluation report is produced
